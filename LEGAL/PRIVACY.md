# 隐私政策

**生效日期**：2026-08-21（v1.0）
**运营主体**：泡泡文化（以下简称「我们」）

本政策说明泡泡直播 Paopao Live 在注册、激活与使用过程中收集哪些数据、如何使用、如何保护。请在使用前阅读。

---

## 1. 我们收集的数据

### 1.1 购买与账户数据
- 订单信息：订单号、支付渠道（支付宝/微信/Lemon Squeezy）、金额、支付状态、发票信息；
- 账户信息：注册邮箱、Key 绑定信息、设备指纹（用于并发激活数校验，**不采集硬盘序列号用于追踪**）。

### 1.2 激活与授权数据
- License Key 状态、激活时间、设备指纹摘要（SHA-256）、软件版本、操作系统类型（仅用于授权与防滥用，不用于画像）。

### 1.3 产品使用数据（本地优先原则）
- **人脸照片与语音样本：仅在本地处理，用于生成数字人模型；原文件不上传服务器**（私有化/企业版全程本地）；
- 生成的数字人模型文件保存在本地磁盘；如需「云端渲染」，仅上传模型摘要与渲染任务参数，不上传你的原始照片/音频；
- 匿名化崩溃报告与性能指标（需你在设置中同意，默认关闭，可随时关闭）。

### 1.4 直播内容
- **我们不在云端存储你的直播脚本、评论数据、推流内容**。话术库保存在本地。

## 2. 数据的使用目的

| 数据 | 用途 |
|---|---|
| 订单/支付 | 开通授权、开发票、对账、退款 |
| 设备指纹摘要 | 校验并发激活数、防盗版 |
| 版本/系统信息 | 兼容性支持、故障排查 |
| 崩溃报告（可选） | 修复缺陷（匿名化，不含你的直播内容） |

**我们不会**：出售你的个人数据；将你的数据用于广告投放；向第三方共享可识别你身份的数据（法律要求或支付渠道对账除外）。

## 3. 数据共享

- **支付渠道**（支付宝/微信/Lemon Squeezy/Stripe）：订单状态回传，用于开通授权；
- **对象存储**（如你启用云端渲染）：仅传输渲染所需参数，采用传输加密；
- **法律要求**：司法机关依法调取时，我们在最小必要范围内配合。

## 4. 数据存储与期限

- 订单与授权数据：保留至你注销后 3 年（税务要求）；
- 设备指纹摘要：授权期间保留，终止后 90 天删除；
- 崩溃报告：90 天后自动删除。

## 5. 数据安全

- 传输：全链路 TLS 1.2+；
- 存储：敏感字段加密（AES-256）；
- 访问：最小权限，操作留痕；
- 安全事件：发生数据泄露将在 72 小时内通知你并报告监管部门。

## 6. 你的权利

依据《个人信息保护法》，你有权：
- 查询、复制你的个人信息；
- 更正、补充不准确的信息；
- 删除你的个人信息（注销账户后我们将删除，除法律要求保留的订单数据）；
- 撤回同意（如关闭崩溃报告）；
- 注销账户：通过1169202852@qq.com提交，15 个工作日内完成。
