# 演示素材（上架前替换为真实素材）

本目录用于存放公开仓库中的产品截图与演示素材，供 README 引用。

## 建议结构

```
assets/
├── screenshots/
│   ├── 01-main-window.png        # 主界面
│   ├── 02-avatar-editor.png      # 数字人形象编辑
│   ├── 03-voice-clone.png        # 语音克隆
│   ├── 04-script-engine.png      # 话术/脚本引擎
│   ├── 05-comment-reply.png      # 评论自动互动
│   └── 06-license.png            # 激活页
└── demo/
    └── demo-60s.mp4              # 60 秒演示视频（超过 2GB 请勿入库，放对象存储并贴外链）
```

## 注意

- 截图中的真实客户信息、License Key、账号信息必须打码；
- 演示视频中涉及真人出镜的，需取得本人书面授权；
- 按《人工智能生成合成内容标识办法》，演示画面中的 AI 生成内容需保留显式标识，
  不要为了好看把标识 P 掉——这本身就是卖点。
